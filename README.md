# 🎓 AI Career Guide

An AI-powered Career Guidance Web Application built using **Python, Flask, Google Gemini AI, HTML, CSS, and JavaScript**.

AI Career Guide helps students make smarter career decisions after **10th, 2nd PUC, and Degree** by providing career recommendations, college prediction, scholarships, AI guidance, skill roadmaps, and professional resume generation.

---

# 🚀 Features

## 👨‍🎓 Career Guidance

- Career suggestions after 10th
- Career suggestions after 2nd PUC
- Career suggestions after Degree
- Personalized career recommendations

---

## 🤖 AI Career Assistant

Powered by **Google Gemini AI**

- Ask career-related questions
- Career planning
- Course guidance
- Future roadmap
- Skill suggestions

---

## 🏫 College Predictor

### KCET College Predictor

Predict suitable colleges based on KCET Rank.

### COMEDK College Predictor

Predict colleges using COMEDK Rank.

---

## 📈 Percentage Based Career Suggestions

Students can enter their percentage and receive suitable career options.

Supported Categories

- 90–100%
- 80–89%
- 70–79%
- 50–69%

---

## 🎓 Scholarships

Scholarship recommendations for students based on education level.

# ⚙ Installation

Clone Repository

```bash
git clone https://github.com/shanthamurthykr/AI-Career-Guide.git
```

Open Project

```bash
cd AI-Career-Guide
```

Install Requirements

```bash
pip install -r requirements.txt
```

Run Application

```bash
python app.py
```

Open Browser

```
http://127.0.0.1:5000
```
