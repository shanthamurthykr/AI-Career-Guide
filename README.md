# 🎓 AI Career Guide

An AI-powered Career Guidance Web Application built using **Python, Flask, Google Gemini AI, HTML, CSS, and JavaScript**.

**AI Career Guide** helps students make smarter decisions about education, careers, skills, scholarships, competitions, learning, and future planning.

The application supports students at different stages including **Young Stars, 10th Students, 2nd PUC Students, and Degree Students**.

# 🔑 Gemini API Configuration

The application uses Google Gemini AI for AI-powered features.

Configure your Gemini API key in `app.py`:

```python
from google import genai

client = genai.Client(
    api_key="YOUR_GEMINI_API_KEY"
)
```

**Do not publish your real API key on GitHub.**

For production use, store the API key in an environment variable.

---

# 🔐 Environment Variable Example

Windows PowerShell:

```powershell
$env:GEMINI_API_KEY="YOUR_GEMINI_API_KEY"
```

Then use it in Python:

```python
import os
from google import genai

client = genai.Client(
    api_key=os.environ.get("GEMINI_API_KEY")
)
```
